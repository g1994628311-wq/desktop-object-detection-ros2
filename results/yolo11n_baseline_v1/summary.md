# YOLO11n Baseline V1 实验总结

## 结论

第一版 YOLO11n baseline 已在 RTX 4060 Laptop GPU 上成功训练。训练请求 100 epochs，因验证指标停止改善而在 73 epochs early stopping；按 Ultralytics fitness 选择的最佳模型来自 epoch 54。纯训练约 128.2 秒，包含正式 val/test 评估和预测可视化的完整流程约 163.4 秒。

数据仍采用原有 Session 级划分：train 47 张/63 个目标，val 23 张/47 个目标，test 17 张/58 个目标。训练期间没有使用 test，也没有根据 test 结果调参。

| Split | Precision | Recall | mAP50 | mAP50-95 |
|---|---:|---:|---:|---:|
| val | 0.8942 | 0.8857 | 0.9558 | 0.8579 |
| test | 0.8345 | 0.7812 | 0.8252 | 0.5977 |

## Test 各类别

| Class | Precision | Recall | AP50 | AP50-95 |
|---|---:|---:|---:|---:|
| mouse | 1.0000 | 0.7226 | 0.8750 | 0.5345 |
| keyboard | 0.7811 | 0.8938 | 0.9397 | 0.6167 |
| laptop | 0.7220 | 0.6667 | 0.6786 | 0.4236 |
| cup | 0.9645 | 0.9231 | 0.9300 | 0.7733 |
| headphones | 0.7051 | 0.7000 | 0.7029 | 0.6404 |

按 AP50-95，表现最好的是 **cup**，最弱的是 **laptop**。keyboard 虽然实例最少，但本次 test AP50 达到 0.9397；其 Precision 0.7811 和训练样本仅 3 个实例说明结果仍不稳健，P02-P05 仍应重点补充不同角度、背景、尺度和距离的独立键盘。

## 主要错误

- S04 边缘或大幅出画面的目标容易漏检，例如独立鼠标近景和只露出一部分的 laptop。
- keyboard 与 laptop 在极端截断场景存在混淆；模型曾把键盘附近的画面区域低置信度识别成 laptop。
- 遮挡、重叠 headphones 的召回和定位下降，并出现重复或额外检测。
- 多目标困难图中存在低置信度但类别正确的预测，说明场景复杂度比 val 明显更高。

完整的程序化 IoU 匹配记录见 `error_cases.csv`；预测图仅保存在本地忽略目录。

## 过拟合判断

存在轻度过拟合/验证平台期迹象，但不是训练崩溃。epoch 54 的 val mAP50-95 为 0.8537，最后 epoch 73 降至 0.7991；同期训练分类损失由 0.759 降至 0.655，而验证表现没有继续提高。Early stopping 和 `best.pt` 选择避免了使用末轮权重。困难 test 的 mAP50-95 比 val 低约 0.26，主要反映数据量很小、训练/验证场景有限以及 S04 分布更难。

## 下一步建议

优先继续采集 P02-P05，而不是立即换大模型或针对 test 调参。重点增加 laptop、headphones、keyboard，以及边缘截断、遮挡、远距离、多实例和背景变化；同时为各 split 增加独立 negative Session。随后用完全相同的训练入口再做下一版实验。当前模型已具备 PC 端 baseline 检测能力，可以进入独立数据补充与后续部署可行性实验，但不应视为最终模型。
