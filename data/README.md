# Dataset

The dataset contains five desktop object classes:

- mouse
- keyboard
- laptop
- cup
- headphones

## Contributors

Five group members collect data independently.

Contributor IDs:

- P01
- P02
- P03
- P04
- P05

## Session Naming

Each collection session uses:

    PXX_SXX

Example:

    P01_S01
    P03_S04

Image naming format:

    PXX_SXX_TYPE_XXXX.jpg

Examples:

    P01_S01_MOU_0001.jpg
    P02_S02_MIX_0015.jpg
    P05_S05_NEG_0008.jpg

## Data Storage

Large raw and annotated image files are excluded from normal Git tracking.

The final submission dataset will be packaged separately.
